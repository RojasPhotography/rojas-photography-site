# Rojas Photography — Content Creation Plan

> Character → Problem (External/Internal/Philosophical) → Guide (Alfonso) → Plan → Call to Action → Stakes → Success Vision

## CONTENT PRINCIPLES (Every Page/Post)

### StoryBrand Checklist
- [ ] **Character:** Who is this page for? (Be specific — "4th-year medical student" not "professional")
- [ ] **External Problem:** What tangible problem do they have?
- [ ] **Internal Problem:** How does it make them FEEL? (embarrassed, anxious, behind)
- [ ] **Philosophical Problem:** Why is this WRONG? ("You shouldn't have to...")
- [ ] **Guide:** Alfonso positioned with empathy + authority (not the hero — the Yoda)
- [ ] **Plan:** 3-step process, clear and simple
- [ ] **Call to Action:** Direct CTA (Book Your Session / Get a Quote) — not passive
- [ ] **Stakes:** What happens if they DON'T act? (Be specific)
- [ ] **Success Vision:** Paint the picture of life after the session

### SEO Checklist
- [ ] Target keyword in H1, first paragraph, and at least one H2
- [ ] Meta title under 60 characters with keyword + location when relevant
- [ ] Meta description under 155 characters with keyword + benefit + CTA
- [ ] Canonical URL set
- [ ] Internal links to 2–3 related pages
- [ ] FAQ section with 5+ questions (schema markup)
- [ ] Images with descriptive alt tags including location keywords

### AEO Checklist
- [ ] Lead with a direct answer to the main question (first 1–2 sentences)
- [ ] Use Q&A format throughout (H2s as questions, answers in paragraphs below)
- [ ] Include specific numbers, prices, timeframes (AI tools cite specifics)
- [ ] Write authoritatively — not "it depends" but actual answers with context
- [ ] FAQ section at bottom reinforces AEO signals
