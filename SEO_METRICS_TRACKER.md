## 📈 QUICK FORMULAS

Add these to your spreadsheet:

**Week-over-Week Growth**:
```
=(This Week - Last Week) / Last Week * 100
```

**Click-Through Rate**:
```
=Clicks / Impressions * 100
```

**Conversion Rate**:
```
=Conversions / Total Users * 100
```

**Average Revenue Per Lead**:
```
=Total Revenue / Total Leads
```

**ROI from SEO**:
```
=(Revenue from SEO - SEO Costs) / SEO Costs * 100
```

## 🎓 HOW TO USE THIS DATA

**Making Decisions**:

1. **If impressions are high but clicks are low**:
   → Improve meta descriptions and titles

2. **If clicks are high but conversions are low**:
   → Improve landing page CTAs and content

3. **If ranking is stuck**:
   → Add more content, get more backlinks, improve page quality

4. **If competitor is outranking you**:
   → Analyze their content, get more reviews, improve technical SEO

5. **If traffic is growing but leads aren't**:
   → Check conversion funnel, improve CTAs, A/B test booking process

---

**Remember**: Data without action is just numbers. Use these insights to make improvements every week!
