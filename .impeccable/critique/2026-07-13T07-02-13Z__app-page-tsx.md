## Anti-Patterns Verdict
Top half: no slop — real photograph hero, 4 restrained kickers, no numbered scaffolding, editorial two-lane layout, specific named proof. Bottom half drifts: Beyond Headshots is a 4-identical-card grid; testimonials are the stock 3-card template with no faces and no Google-reviews link; "proud" ×4 (PRODUCT.md forbids catchphrase repeats); "Imagine Sharing Imagery…" is the imagination-prompt LLM formula. Detector: 4 side-tab warnings, all the transparent hover border in the mobile nav drawer (low impact, effectively dead styling on touch); page/components/globals otherwise clean; prior legacy-green finding fixed. Browser overlay skipped: no mutable-injection automation.

## Priority Issues
- [P0] Page invisible below hero without JS: SectionReveal SSRs class="reveal" (opacity:0), removed only by IntersectionObserver in useEffect; 10/11 sections wrapped. Slow-3G users see blank page until hydration; JS failure = blank forever; non-JS crawlers see nothing (SEO mandate risk). Fix: visible by default, add pre-animation class via JS before first paint, or noscript/scripting:none override.
- [P1] Price findable only in collapsed FAQ at position 10/11 ("$150 + $150/image" nowhere near any CTA). Note: Alfonso previously chose logistics-only reassurance (no price) — decision needed.
- [P1] Lane naming drift: Studio Headshots / In-Studio Headshots / premium-headshots URL; On-Location Headshots / On-Site Photography / Headshot Day for Your Team; nav pill "Book a Session" vs "Book a Studio Session". Canonize one pair, propagate nav/footer/lanes.
- [P1] Bottom-half redundancy: discovery-call CTA → green band → newsletter section → CTASection → footer newsletter bar = 9 asks; homepage NewsletterSignup + footer NewsletterFooterForm = 2 signups (CLAUDE.md violation). Fix: delete homepage newsletter section (footer bar stays); fold discovery-call ask into green band; CTASection remains sole closer.
- [P2] Hero image (headshot-ceo-nutrition.jpg) reused as largest bento tile — reads as thin portfolio. Swap tile.
- [P2] Testimonials placed AFTER the main CTA band; H2 is a slogan ("…Actually Proud Of" = 4th "proud", no keyword); no link to 60+ Google reviews. Move above band, retitle with keyword, add reviews link.
